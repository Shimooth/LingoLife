# KayKit City Builder Bits runtime subset

This directory contains the complete glTF runtime subset used by LingoLife:
buildings `A`–`H`, every road shape, the blank base tile, all street furniture,
vegetation and vehicles included in the free pack. Source-format duplicates
and the unused `building_*_withoutBase` variants are not shipped.

- Creator: Kay Lousberg / KayKit
- Source: https://kaylousberg.itch.io/city-builder-bits
- License: CC0-1.0; see `LICENSE.txt`

Runtime presence and external buffer/texture references are checked by
`web/scripts/check-runtime-assets.mjs` during linting.
