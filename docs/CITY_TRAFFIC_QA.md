# 城市车流修复与验收

日期：2026-09-26。本轮仅本地修改，未提交、推送或部署；没有修改玩家数据或管理员已发布地图。

## 玩家看到的变化

- 车辆不再只绕左下街区：默认地图的五个街区环路都有双向车流，西、东、北三个云路出口可以进出。
- 高档最多 28 辆、低档最多 20 辆；降低画质时仍保留每条路线，不把右侧街区或出城车流全部删掉。
- 开车与停车分开：合法车位保留静态车，落在道路／人行空间上的旧静态车不再渲染。新默认布局将这些车放到车站停车场，已有发布地图不自动改写。
- 同向车留间距，交叉路口先让行，出口没有整车空间就不驶入路口。云路尽头透明淡出后才循环，不在城内瞬移，也不靠缩小车身藏消失。
- 根据素材实际轮胎位置贴地，停车位和行驶车分别对齐；三个出口增加固定锚点的局部云团，遮住道路截断，不增加全屏雾。

## 为什么原来只剩左边的车

公开线上 `/api/v1/world-layout` 的只读检查确认：100 块道路、三个出口，以及三辆位于主干道的静态车。发布数据用模型地址和四位小数的旋转，不包含前端 `surface` 标记。

旧版 `WorldScene` 把这些道路全部转换为 `surface: city`，但旧车流逻辑只在 `skyway` 上找出口，因此六条跨城路线消失。另外 `trafficLoop` 只找第一个闭环，最后只渲染同一个西南环的双向共六辆车。原来只测无布局的默认地图，没有覆盖正式发布数据的转换链。

目前按道路真正的开口构建连接图，从实际云路端部识别出口。默认发布格式和内置道路均得到 16 条路线：6 条跨城、5 个街区各 2 个方向，覆盖全部 100 块道路。

## 实现边界

- 这是匿名城市背景车流，不是 NPC 拥有汽车或真实驾驶的玩法，也没有红绿灯时相仿真。
- 路线是精确直线／圆弧，不再用会偏出道路的整体样条。车体碰撞按完整模型占地计算，不只检查车心。
- 删除道路、旋转封闭开口时，不会跨空隙连接或把普通死路当作城市出口。暂不支持坡道和异形缩放：非默认高度 `.245`、缩放 `1.3` 的道路不加入车流图，避免车开到空中。停车检查仍检查所有实际道路。
- 停车过滤是渲染保护，不会悄悄把管理员设置的车辆搬到别处或保存地图。当前已有发布地图的三辆路中车会隐藏，停车场原有车辆保留。
- 开启“减少动画”时停止背景车流；低档仍保留全部方向。没有改变天气、居民生活模拟或账号。

## 验收结果

1. 正式发布数据格式（无 `surface`、四位小数角度）与内置地图路线一致；检查三出口、所有街区、断路／旋转／空路网、闭环与转弯连续性。
2. 20／28／32 辆车分别进行 10 分钟规则模拟，合计 1,034 次完整行程，没有车体碰撞，没有车辆卡住一分钟；每辆车都多次完成路线。
3. 实际 glTF 层级边界与轮胎接触检查：默认八辆停车、五处旧路中停车、建筑候选地块、人行空间、缩放与跨来源重复过滤。
4. 隔离 Chrome 实际渲染六种情况：发布地图桌面、390×844 低档、内置俯视、东出口断路、空路网、减少动画。观察到桌面 28 辆和低档 20 辆均有位移，四个方向都有车流；断路后不保留虚假出口，没有浏览器异常。已查看桌面、手机和俯视截图，不仅检查编译。
5. 前端完整 lint、类型检查与生产构建通过（保留已有 Three 大包警告）；后端布局相关测试 **63 passed**。

上述手机检查是浏览器尺寸仿真，不代表手机 GPU 帧率、发热或十分钟真机稳定性。模拟无碰撞也不等于所有未来任意编辑地图都已验收。

## 复现入口

Vite 启动后直接打开，不需要账号或后端：

- `/scripts/fixtures/traffic-city.html?source=published`：复现旧线上格式与错误静态车位置，使用修复后的正式场景渲染。
- 加 `&quality=low` 查看低档，`&view=top` 查看俯视。
- `source=builtin`／`source=broken`／`source=empty`，或 `&reduced=1` 做边界检查。

在 `web` 目录：

```sh
npm run lint
npm run typecheck
npm run build
node --experimental-strip-types scripts/check-ambient-traffic.mjs
node --experimental-strip-types scripts/check-traffic-parking.mjs
```

已有独立 QA Chrome（调试端口 19226）和本机 Vite 5173 时：

```sh
node --experimental-strip-types scripts/check-world-traffic-browser.mjs
```

只连接隔离浏览器，不连接个人浏览器资料。截图写入 `/tmp/lingolife-traffic-*.png`，不包含真实居民或账号；`QA_CDP_URL`、`QA_BASE_URL` 可指定本机测试端口。
