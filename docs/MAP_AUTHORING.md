# 3D 天空之城地图编辑指南

当前地图作者工具用于手工摆放树木和街道小品，适合在本地调整城市细节。它不会开放给普通玩家，也不会直接修改服务端数据。

## 打开工具

先启动本地前端，再在地址后加上 `?mapEditor=1`：

```bash
cd web
npm run dev
```

默认地址为：

```text
http://127.0.0.1:5173/?mapEditor=1
```

点击“地图作者工具”后可以放置圆冠树、高树、花坛、灌木、长椅、路灯、消防栓和木箱。工具支持选择、移动、旋转、删除和重置，坐标自动吸附到 `0.25` 世界单位网格。

## 防止摆放冲突

每次放置、移动、旋转或导入都会使用同一套空间校验。以下区域不能摆放：

- 马路及路面边缘；
- 建筑地块和固定院落；
- 已有树木、车辆及街道设施；
- NPC 当前站位和当日行走路线；
- 天空之城平台边缘和其他自定义装饰。

非法操作只显示原因，不会覆盖当前草稿。城市布局更新后若旧草稿变得不合法，对应装饰会暂时隐藏，只有点击“清理无效装饰”才会删除。

## 保存、预览与发布

- 编辑结果会自动保存在当前浏览器的 `localStorage` 中。
- 去掉 `?mapEditor=1` 后，编辑面板和编辑交互会隐藏，但同一浏览器仍会显示合法的本机草稿，可用于正常玩法预览。
- “导出 JSON”用于备份、换设备或提交正式地图；“导入 JSON”会先完整校验，任何合法格式但位置冲突的装饰都会令本次导入整体取消。
- 本机草稿不会自动同步给其他账号或设备，也不会自动成为线上公共地图。正式发布前需要把导出的 JSON 纳入版本库并经过构建、测试和部署。

建议每完成一片街区就导出一次 JSON 备份，不要把浏览器缓存当作唯一源文件。

## 摄像机操作

- 总览：拖拽旋转，右键拖拽平移，滚轮或双指缩放。
- 俯瞰：右键拖拽平移，滚轮或双指缩放。
- 跟随居民：镜头自动平滑追随并维持近景构图，避免手动操作后与居民脱离。

总览和俯瞰模式中的手动操作会立即取得镜头控制权，不应再被初始化构图或旧的聚焦动画强制还原。跟随镜头使用稳定的地块朝向和时间阻尼，避免经过道路格边界时左右跳动。

## 修改道路与内置城市内容

当前可视化工具只编辑装饰，不直接改变路网和建筑。内置道路、基础树木和街道设施仍由以下文件维护：

- `web/src/three/world/worldData.ts`
- `web/src/three/world/worldNavigation.ts`

修改后至少运行：

```bash
cd web
npm run check:world-roads
npm run check:world-decorations
npm run check:world-navigation
npm run check:world-camera
```

道路检查会验证相邻接口双向匹配、整张路网连通且三条云路出口仍然存在，防止再次出现断路或路缘互相顶住。
