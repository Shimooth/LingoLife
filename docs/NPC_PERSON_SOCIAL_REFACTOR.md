# 居民作为“人”：个人视角与持续社交第一版

日期：2026-09-26。状态：本地实现；未提交、未部署。保留现有账号、居民、关系、聊天与历史片段，不需要清库或重新入住。

## 1. 这次要改变的体验

以前常见的体验是：两个人碰到一个问题，说完几句，接着各做各的。即使有关系和记忆，下一次主动行为也不一定承接这件事。

这一版让事情在人物身上留下有限的延续：**我知道什么 → 我怎么看 → 我还在意什么 → 我愿意找谁 → 对方现在愿不愿意回应 → 此后的选择发生变化**。

这是对原生活模拟的增量重构，不是把世界交给 AI 任意编造，也不是声称已经模拟完整的人类心理。

## 2. 玩家会看到什么

| 变化 | 实际行为 | 不会发生的事 |
|---|---|---|
| 人有不同的在意点 | 同一件事按个人价值、旧关系和责任归属形成不同评价 | 两个人共享同一份内心结论 |
| 一件事不一定当场结束 | 部分分歧、帮助、错过和约定留下心事，有空再去找对方 | 每件日常小事都变成强制任务 |
| 对方有自己的生活 | 可以愿意听、暂时推迟、保持距离，或只是表示知道了 | 说完道歉就自动原谅、加好感 |
| 第三人开始有关联 | 亲眼看见公共做饭或清洁的居民，之后可以告诉另一位同住者 | 不在场的人自动知道一切，或传播卧室里的秘密 |
| 承诺以行动为准 | 双方同意后，实际到场并共同完成才算兑现 | 台词说“下次一起”就凭空建立日程 |
| 有限记忆继续影响行为 | 近期经历影响选人；忘掉来源后不再拿它发起续谈 | 从事件档案把已忘掉的小事重新拼回来 |

创建居民和角色工作室新增折叠的「内心设定（选填）」：

- 在诚实守信、公平互惠、照顾他人、自主与边界、陪伴与归属、成长与成就中，按顺序选择最多三项。
- 填写「希望自己是怎样的人」。这是自我形象，不等于已经做到了，也不会覆盖明确的生活边界。
- 不填也能继续玩：只从现有资料中识别有限的明确线索，不能随意给陌生描述添加人格。
- 修改影响后续评价与表达，不重写过去片段的人格和结论。

地图仍用简短的可见状态，例如「正在去找 Nora」「在等 Nora 说会儿话」。不新增一整屏心理数值，也不把角色内心全部展示给玩家。

## 3. 三条已接通的生活链

### 分歧之后再开口

真实借物/噪声/家务分歧结束 → 各自记住自己的经历与感受 → 合适的居民仍想说清楚 → 等对方有空、走到同一公共地点 → 尝试开口。

对方可以听，也可以暂时不聊或保持距离。一次听取不消除原问题。这里没有一套固定的道歉台词，AI 在真实的身份、原事和回应范围内写对白。

### 没有在场，也可能后来听说

A 在厨房做过饭 → 当时同处的 B 确实看见 → B 后来遇到 C，提起这件公开小事 → C 得到带来源的“听说”，而不是亲历记忆 → C 可能之后去找 A 聊聊。

当前只做一跳公开转告；不是全城八卦网络。不能由“做过饭”推导出“C 吃了这顿饭”“还有剩菜”“A 是为了 C 做的饭”。

### 约定有后果，但不强行归罪

现有共同活动或双方接受的日程邀请 → 接受回执 → 实际共同执行 → 完成或落空回执 → 对相处的理解与后续关心。

拒绝邀请不是违约；没完成也不自动代表背叛。没有实际原因资料时，只能询问，不能编造“他故意爽约”。

## 4. 为什么不会变成互相纠缠

- 每人同时最多四件活跃心事，同目标同类型一天内不重复添加。
- 普通后续至少等 25 分钟；推迟后间隔 12 小时，同件事最多尝试两次。
- 日程、工作、学习、睡觉、紧急需要和已经接受的共同活动优先。
- 不闯进卧室、浴室；需要真实公共共处和到场时间，不能隔空完成交谈。
- 转告心事最多保留两天，其他心事最多四天；来源提前遗忘则提前结束。
- 不为轮询、刷新、重复结算多发奖励或多造事件；离线推进与分段在线推进采用相同转换规则。

## 5. AI 现在负责哪一段

本轮没有新增逐秒 AI 调用。世界仍由规则确定位置、可做的事、知情范围、主观评价、接近目标和回应结果；原来的 DeepSeek 表达流程负责把这些内容写成符合人物的英文对白和中文翻译。

NPC 间片段：真实相遇 → 固定参与者与各自回应 → 冻结当时的个人视角 → AI 编写/校对 → 播放与缓存。后续重看不带入后来才形成的关系、恋爱或见闻。旧片段保留原缓存，不批量重写。

与玩家聊天：原有人设、当前活动、会话和可用记忆 + 发言者经过安全过滤的个人视角 → 原流式回复链。玩家不会从接口直接拿到全部心理资料；这一版也没有把所有未披露心事自动讲给玩家。

当前主观评价是有边界的规则模型，**不是每人每步都让 AI 自主思考**。代码有受约束解释提案的校验入口，但没有接入新的 AI 思考任务，不能把入口存在当作功能完成。

## 6. 事件少，接下来该增加什么

问题不只是触发概率。原来大量“独处、做饭、阅读”是日常动作，少数可交互的社会起因被反复使用；单纯提高概率容易变成不停借东西、争厨房、礼貌地和好。

建议优先扩展**能实际执行、能留下结果的生活机会**，而不是堆固定剧情：

1. **个人小目标与共享活动互相影响。** 例如练习一道菜，需要找人试吃；有人愿意、有人成本太高、有人给出不同意见。要有真实准备、参与、评价和后续，不只生成标题。
2. **一件事有不同条件。** 同样做饭，时间紧不紧、食物够不够、谁做过贡献、谁今天想独处，会产生不同走向。
3. **让关系和记忆改变下一次机会。** 上次没赶上的人再邀、刚争执的人绕开、收到帮助的人回报；让玩家认出“这是上次那件事的后来”。
4. **控制玩家看到的节奏。** 保留平静生活，对重复普通片段降频，优先展示首次发生、人物反常、关系转折和可见后果。后台活动量不等于玩家应被打扰的次数。

本轮先补了第 3 项的有限后续与公开转告基础；没有声称补齐新的工作、创作、社团或城市活动系统。下一轮最合适的是做一条贯穿几天的个人目标，再与已有吃饭、试爱好、共同练习等执行系统组合。

## 7. 验收与复现

所有自动模拟都使用虚构居民/临时数据库，不操作真实账号或调用收费 AI。

```sh
# 后端规则、服务契约及旧功能回归（Mac 当前环境）
backend/.runtime/.venv/bin/python -m pytest backend/tests -q

# 固定种子的生活模拟，无服务器、数据库或网络依赖
PYTHONPATH=backend backend/.runtime/.venv/bin/python backend/scripts/probe_person_social_life.py --hours 48
PYTHONPATH=backend backend/.runtime/.venv/bin/python backend/scripts/probe_person_social_life.py --hours 168 --residents 8

# 前端（进入 web 目录后）
npm run lint
npm run typecheck
npm run build
```

浏览器复现页：`http://127.0.0.1:5173/scripts/fixtures/onboarding-preview.html`，只在预览中提交表单，不写账号。`web/scripts/check-personal-values-browser.mjs` 检查默认折叠、三项上限、顺序、切换居民隔离、390px 触屏布局与最终请求内容；需要前端服务和独立的 Chrome CDP 会话。

已覆盖的行为边界：未知事实不能参与评价；听说不等于亲历；公共见闻不得扩展到私密；重复执行幂等；丢弃记忆不能复活；旧存档平滑增加新状态；新价值修改即时生效；真实到场才能续谈；推迟/疏远尊重边界；没有新的双向同意不能制造承诺；历史片段不能获得未来信息。

本轮没有真实 DeepSeek 试听、手机真机帧率测试或线上压测。浏览器尺寸验收不等于真机性能验收，规则测试不等于台词已经足够自然。详细最终结果记录在 [交接手册](SESSION_HANDOFF.md)。

最终回归：后端 **866 项通过**；前端完整 lint、类型检查、生产构建通过；隔离浏览器中英文和手机尺寸交互验证通过。8 人连续一周的虚构模拟产生了 128 次后续会面、16 次公开转告和 8 次真实履约，证明链路能自然发生，不表示这些后台片段都应展示给玩家。

## 8. 实现索引与后续边界

- `backend/lingolife/social_mind.py`：事实、个人知情、主观解释、价值与安全投影。每世界事实最多 128 条；每人观察最多 24 条、解释最多 48 条；细节三天后降为大意，并服从原双向记忆的丢弃结果。
- `backend/lingolife/social_continuity.py`：心事、选人权重、承诺回执、公开转告和真实再次相遇。
- `backend/lingolife/life_world.py`：原生活转换中接入上述逻辑，不另开与世界时钟脱节的循环。
- `backend/lingolife/life_service.py`：旧存档兼容、当前设定刷新、公开状态和服务端私有表达上下文。
- `backend/lingolife/life_expression.py`、`agent.py`、`ai.py`：两种对话的事实约束和个人视角投影。
- `web/src/components/PersonalValuesFields.tsx`：创建与编辑复用的中英文选填区。

仍未实现：自由 AI 长程规划、可变群体规范、多跳传闻与求证、全部个人目标的多阶段玩法、玩家主动建立结构化承诺、新的骨骼动画/资产。不能因本轮接通了个人视角就把这些目标标为完成。
