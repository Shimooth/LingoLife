# NPC 互动说话风格（2026-09-06）

本次改动：让 NPC 之间的日常对话少一些通用客套，多一些性格差异、生活细节和对上一句的回应。没有更改行动选择、关系结算或增加 DeepSeek 请求。

## 实际链路

```text
生活模拟产生碰撞／生活事实
  → 碰撞规则先决定双方的回应意图（接受、等待、拒绝、争执等）
  → 读取双方性格、双向关系，以及碰撞事实
  → interaction-scene-v2 编排开场、回应、反应、收束
  → 中英台词 + 情绪 + 既有动画提示 + 播放时长
  → 随故事持久保存
  → 前端播放；旧故事按原保存台词回放
```

NPC ↔ NPC 的这个路径是本地规则与双语台词库，不是玩家聊天使用的 DeepSeek 链路。优点是无新增请求费用、即时且可回放；局限是尚不能围绕任意自由文本人设即兴长谈。

## 本次覆盖

- 16 类生活话题：厨房、浴室、电视、陪伴、错过碰面、洗碗、照顾负担、隐私、借东西、计划受阻、缺食材、噪音、比赛、倒垃圾、私人物品食物、共享食物。
- 所有既有回应意图都有简短口语版本。高频意图另有完整句子的性格变体，不是只加“嗨”或“我们直说吧”。
- 内向：简短、允许安静，不默认结巴；直接：明确要求，不等于骂人；温暖：关心但有边界；幽默：围绕当下的事情打趣；普通：自然口语。
- 性格来自实际可编辑的 personality / quirks / habits 编译轴，或已有 axes / persona_axes。没有把玩家自由填写的中文爱好直接塞进英文台词，也不凭空编造共同经历。
- 熟人打趣需要双向熟悉、好感与信任，以及低紧张程度。单方面亲近不会被写成双方好友；不会凭亲近直接编造恋爱关系。
- 冲突和紧张不会被通用“各退一步”自动化解；涉及隐私、私人食物、借物和照顾负担时收住笑话。
- 对方拒绝时，合作型开场会接住拒绝，不再重复发出邀请；固执、对抗型意图仍能坚持。
- 同类新事件的部分回应与收尾按事件 ID 稳定选择；轮询、刷新不会重新抽台词。
- 已消费食物的事实事件询问吃后感受，不再重放开饭邀请。拒绝／留到以后只指“再吃／可能剩余的部分”，不否认已发生的消费，不凭空增加食物。

## 共享晚餐

邀请、饱了、累了、想独处、手头忙、准备、等饭、等别人、吃完、收拾、拒绝收拾使用同一套五类语气。餐次开始时冻结语气类别；中途编辑人设不会令一个人的这顿饭台词忽然换风格。该类别只留在服务端，公共 DTO 不暴露性格轴。

仍由真实的饥饱、疲劳、隐私偏好、位置和行动决定是否参加，台词层不会替角色接受邀请。吃完不代表洗碗，表示愿意洗也不代表已经洗完。做饭的人吃完自己的饭不再向自己说“谢谢这顿饭”。

## 文件与检查

| 文件 | 职责 |
| --- | --- |
| `backend/lingolife/npc_voice.py` | 统一的性格语气选择 |
| `backend/lingolife/interaction_copy.py` | 场景开场、意图台词、性格变体与话题回扣 |
| `backend/lingolife/interaction.py` | 接话、关系语气、事实约束、动画与持久化格式 |
| `backend/lingolife/dinner_copy.py` | 共享晚餐阶段的双语语气 |
| `backend/tests/test_npc_spoken_voice.py` | 全话题／语气覆盖、拒绝、矛盾、事实、回放与餐次测试 |

在 `backend` 下执行：

```sh
.venv/bin/python -m pytest tests/test_npc_spoken_voice.py tests/test_life_interactions.py tests/test_dinner.py -q
.venv/bin/python -m pytest -q
```

本地查看：打开 `http://localhost:5173`，观看新发生的生活事件或新餐次。已保存的旧对话不批量覆盖，不需要清空账号或世界数据。本次不部署生产服务器。

后续如果要支持任意人设细节即兴发挥，可在当前确定的事实、回应意图和场景结构之后增加受约束的 AI 台词润色，失败时回退到本地台词；不能让润色模型修改接受／拒绝、动作结果或关系数值。
